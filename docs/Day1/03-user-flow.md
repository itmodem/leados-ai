# LeadOS AI — User Flow

## 1. Primary User Flow

```text
LOGIN
  ↓
DASHBOARD
  ↓
CREATE / IMPORT LEAD
  ↓
LEAD RESEARCH
  ↓
LEAD SCORE
  ↓
AI ANALYSIS
  ↓
QUALIFICATION
  ↓
OUTREACH
  ↓
FOLLOW-UP
  ↓
SALES PIPELINE
  ↓
MEETING
  ↓
PROPOSAL
  ↓
NEGOTIATION
  ↓
WON / LOST
  ↓
ANALYTICS
```

## 2. Lead Acquisition Flow

## 6. Core Business Logic

The system should follow:

**Your Business Logic → Structured Data → AI Assistance → Sales Action**

AI should assist the sales process rather than independently define the core business rules.
